# burpweb Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a CLI that turns a Burp Suite "Save items" XML export into a local replay proxy, so the user can browse the tested website offline at its real URLs.

**Architecture:** A stdlib-only loader parses the Burp XML into `Record`s. A pure matcher picks a record for each incoming request (EXACT → FALLBACK → HEAD → MISS). A cleanup step makes the stored response safe to resend. A mitmproxy addon sets `flow.response` in the `request` hook, so nothing ever goes upstream. A CLI runs mitmproxy's `DumpMaster` in-process, and an optional addon launches a dedicated Firefox profile that trusts the mitmproxy CA.

**Tech Stack:** Python ≥ 3.12 (developed on 3.14), mitmproxy 12.2.x, pytest, uv, hatchling. Firefox and NSS `certutil` are only needed for `--browser`.

**Spec:** `docs/superpowers/specs/2026-10-15-burpweb-design.md`

## Global Constraints

- `requires-python = ">=3.12"`; dependencies: `mitmproxy>=12.2` (runtime) and `pytest>=8` (dev group only).
- The proxy listens on `127.0.0.1` only. The default port is `8081`, and `--confdir` defaults to `~/.mitmproxy`.
- **Never contact the real target.** Set the mitmproxy options `connection_strategy="lazy"`, `upstream_cert=False` and `http3=False` (verified: with these set, HTTPS for an unresolvable host like `target.invalid` is served purely from the addon).
- The loader (`burp_xml.py`) and matcher (`matcher.py`) must not import mitmproxy.
- Log line format: `EXACT|FALLBACK|HEAD|MISS  METHOD URL  -> status`. FALLBACK and HEAD lines append `  [burp #N]`.
- Native `.burp` files, WebSocket replay, static mirroring, passthrough and Chromium are out of scope.
- Tests must never touch the real `~/.mitmproxy` or the user's Firefox profiles. Use `tmp_path` everywhere.

**Additions beyond the spec** (needed by the design, flagged for review):
- `Record` gains `request_content_type: str` (required for body normalization) and `origin`/`url` properties.
- Response cleanup lives in its own module, `cleanup.py`. Besides the spec's list, it also strips the hop-by-hop headers `Connection`, `Keep-Alive`, `Proxy-Connection`, `Transfer-Encoding`, `Upgrade`, `TE` and `Trailer`. These are illegal over HTTP/2, and Firefox talks HTTP/2 to mitmproxy.
- `certutil` deletes and re-adds the CA on every launch instead of skipping it when present. That way a regenerated CA, or a different `--confdir`, replaces a stale one.
- `--browser` opens Firefox at the URL of the first captured item.
- mitmproxy's own terminal log is kept at `warn` verbosity, so TLS trust failures and startup errors are visible.

## Review Focus

1. **Raw (non-base64) export containing binary bodies.** This produces invalid XML. The user should get a clear error telling them to re-export with base64 enabled, not a traceback. Pinned by `test_invalid_xml_suggests_base64` (Task 1).
2. **HTTP/2-format Burp items** (`GET /x HTTP/2`, `HTTP/2 200 OK`, lowercase headers). They should load like HTTP/1.1 items. Pinned by `test_http2_format_item` (Task 1).
3. **An empty request body sent with a `Content-Type` header** (e.g. a GET carrying `Content-Type: application/json`). It must exact-match a captured empty-body request regardless of content type. Pinned by `test_empty_body_ignores_content_type` (Task 2).
4. **Captured `Connection: keep-alive` / `Keep-Alive` headers replayed to an HTTP/2 client.** The page must still load. Pinned by `test_strips_hop_by_hop_and_alt_svc` (Task 3) and `test_https_over_http2` (Task 6).
5. **Port already in use.** The user should get a short error with a `--port` hint and exit code 1, not a hang or traceback. Pinned by `test_port_in_use_exits_with_hint` (Task 6).

"""Builders for Burp "Save items" XML and Record objects used across tests."""
import base64

from burpweb.burp_xml import Record

DOCTYPE = """<!DOCTYPE items [
<!ELEMENT items (item*)>
<!ATTLIST items burpVersion CDATA "">
<!ATTLIST items exportTime CDATA "">
<!ELEMENT item (time, url, host, port, protocol, method, path, extension, request, status, responselength, mimetype, response, comment)>
]>"""


def _message(tag: str, data: bytes, b64: bool) -> str:
    if b64:
        text = base64.b64encode(data).decode("ascii")
        return f'<{tag} base64="true"><![CDATA[{text}]]></{tag}>'
    return f'<{tag} base64="false"><![CDATA[{data.decode("utf-8")}]]></{tag}>'


def make_item(
    *,
    request: bytes,
    response: bytes | None,
    host: str = "example.com",
    port: int = 443,
    protocol: str = "https",
    time: str = "Wed Oct 15 10:00:00 UTC 2026",
    b64: bool = True,
) -> str:
    """One <item>. response=None omits the <response> element entirely."""
    resp = _message("response", response, b64) if response is not None else ""
    return (
        f"<item><time>{time}</time><url><![CDATA[{protocol}://{host}]]></url>"
        f'<host ip="127.0.0.1">{host}</host><port>{port}</port>'
        f"<protocol>{protocol}</protocol>"
        f"{_message('request', request, b64)}<status></status>{resp}</item>"
    )


def make_xml(items: list[str]) -> str:
    return (
        '<?xml version="1.0"?>\n'
        f"{DOCTYPE}\n"
        '<items burpVersion="2026.9" exportTime="Wed Oct 15 10:00:00 UTC 2026">\n'
        + "\n".join(items)
        + "\n</items>\n"
    )


def make_record(
    index: int,
    *,
    method: str = "GET",
    path: str = "/",
    query: str = "",
    body: bytes = b"",
    content_type: str = "",
    status: int = 200,
    scheme: str = "https",
    host: str = "example.com",
    port: int = 443,
    headers: tuple[tuple[str, str], ...] = (("Content-Type", "text/plain"),),
    response_body: bytes = b"",
) -> Record:
    return Record(
        index=index,
        time="",
        scheme=scheme,
        host=host,
        port=port,
        method=method,
        path=path,
        query=query,
        request_body=body,
        request_content_type=content_type,
        status=status,
        response_headers=headers,
        response_body=response_body or f"record {index}".encode(),
    )

`src/burpweb/burp_xml.py`:
```python
"""Stream-parse Burp Suite "Save items" XML exports into Records."""

from __future__ import annotations

import base64
import binascii
import re
import xml.etree.ElementTree as ET
from dataclasses import dataclass, field
from pathlib import Path
from urllib.parse import urlsplit

_DEFAULT_PORTS = {"http": 80, "https": 443}
_LINE_BREAK = re.compile(rb"\r?\n")


class BurpXmlError(Exception):
    """The file can't be read as a Burp XML export."""


@dataclass(frozen=True)
class Record:
    index: int
    time: str
    scheme: str
    host: str
    port: int
    method: str
    path: str
    query: str
    request_body: bytes
    request_content_type: str
    status: int
    response_headers: tuple[tuple[str, str], ...]
    response_body: bytes

    @property
    def origin(self) -> str:
        if self.port == _DEFAULT_PORTS.get(self.scheme):
            return f"{self.scheme}://{self.host}"
        return f"{self.scheme}://{self.host}:{self.port}"

    @property
    def url(self) -> str:
        return self.origin + self.path + (f"?{self.query}" if self.query else "")


@dataclass
class LoadResult:
    records: list[Record] = field(default_factory=list)
    skipped_no_response: int = 0
    malformed: list[tuple[int, str]] = field(default_factory=list)


def split_message(raw: bytes) -> tuple[str, list[tuple[str, str]], bytes]:
    """Split a raw HTTP message into (start line, headers, body)."""
    for separator in (b"\r\n\r\n", b"\n\n"):
        head, found, body = raw.partition(separator)
        if found:
            break
    else:
        head, body = raw, b""
    lines = _LINE_BREAK.split(head)
    start = lines[0].decode("latin-1").strip()
    headers = []
    for line in lines[1:]:
        if not line.strip():
            continue
        name, colon, value = line.decode("latin-1").partition(":")
        if not colon:
            raise ValueError(f"bad header line {line[:60]!r}")
        headers.append((name.strip(), value.strip()))
    return start, headers, body


def load(path: str | Path) -> LoadResult:
    """Parse a Burp export. Bad items are counted, never fatal; a bad file raises BurpXmlError."""
    result = LoadResult()
    index = 0
    root = None
    try:
        for event, elem in ET.iterparse(path, events=("start", "end")):
            if root is None:
                if elem.tag != "items":
                    raise BurpXmlError(
                        f"{path}: root element is <{elem.tag}>, expected <items> "
                        "(export with Proxy > HTTP history > Save items)"
                    )
                root = elem
                continue
            if event != "end" or elem.tag != "item":
                continue
            index += 1
            try:
                record = _parse_item(index, elem)
            except ValueError as e:
                result.malformed.append((index, str(e)))
            else:
                if record is None:
                    result.skipped_no_response += 1
                else:
                    result.records.append(record)
            root.clear()  # keep memory flat on large exports
    except ET.ParseError as e:
        raise BurpXmlError(
            f"{path}: not valid XML ({e}). If you exported without base64, re-export with "
            "'Base64-encode requests and responses' enabled."
        ) from None
    except OSError as e:
        raise BurpXmlError(f"{path}: {e.strerror or e}") from None
    return result


def _parse_item(index: int, item: ET.Element) -> Record | None:
    """Return a Record, or None when the item has no response. Raise ValueError if malformed."""
    response_el = item.find("response")
    if response_el is None or not (response_el.text or "").strip():
        return None
    request_el = item.find("request")
    if request_el is None:
        raise ValueError("missing <request>")
    try:
        raw_request = _decode(request_el)
        raw_response = _decode(response_el)
    except binascii.Error as e:
        raise ValueError(f"bad base64: {e}") from None

    request_line, request_headers, request_body = split_message(raw_request)
    parts = request_line.split()
    if len(parts) < 2:
        raise ValueError(f"bad request line {request_line[:60]!r}")
    method, target = parts[0].upper(), parts[1]
    if "://" in target:
        url = urlsplit(target)
        target = (url.path or "/") + (f"?{url.query}" if url.query else "")
    path, _, query = target.partition("?")

    status_line, response_headers, response_body = split_message(raw_response)
    status_parts = status_line.split()
    if (
        len(status_parts) < 2
        or not status_parts[0].upper().startswith("HTTP/")
        or not status_parts[1].isdigit()
    ):
        raise ValueError(f"bad status line {status_line[:60]!r}")

    scheme = (item.findtext("protocol") or "").strip().lower()
    host = (item.findtext("host") or "").strip().lower()
    port = (item.findtext("port") or "").strip()
    if scheme not in _DEFAULT_PORTS or not host or not port.isdigit():
        raise ValueError("missing or invalid protocol/host/port")

    return Record(
        index=index,
        time=(item.findtext("time") or "").strip(),
        scheme=scheme,
        host=host,
        port=int(port),
        method=method,
        path=path or "/",
        query=query,
        request_body=request_body,
        request_content_type=_header(request_headers, "content-type"),
        status=int(status_parts[1]),
        response_headers=tuple(response_headers),
        response_body=response_body,
    )


def _decode(elem: ET.Element) -> bytes:
    text = elem.text or ""
    if elem.get("base64") == "true":
        return base64.b64decode("".join(text.split()), validate=True)
    return text.encode("utf-8")


def _header(headers: list[tuple[str, str]], name: str) -> str:
    return next((value for key, value in headers if key.lower() == name), "")
```

from burpfixtures import make_record
from burpweb.matcher import Incoming, Matcher, Tier


def incoming(method="GET", path="/", query="", body=b"", content_type="", scheme="https", host="example.com", port=443):
    return Incoming(scheme, host, port, method, path, query, body, content_type)


def test_exact_match():
    rec = make_record(1, path="/a", query="x=1")
    assert Matcher([rec]).match(incoming(path="/a", query="x=1")) == (rec, Tier.EXACT)


def test_exact_prefers_most_recent_even_if_error():
    old = make_record(1, path="/a", status=200)
    new = make_record(2, path="/a", status=500)
    assert Matcher([old, new]).match(incoming(path="/a")) == (new, Tier.EXACT)


def test_query_order_insensitive():
    rec = make_record(1, path="/s", query="a=1&b=2&b=3")
    assert Matcher([rec]).match(incoming(path="/s", query="b=2&a=1&b=3"))[1] is Tier.EXACT


def test_form_body_order_insensitive():

    req = incoming("POST", "/f", body=b"b=2&a=1", content_type="application/x-www-form-urlencoded; charset=UTF-8")

`src/burpweb/matcher.py`:
```python
"""Pick the captured response for an incoming request."""

from __future__ import annotations

import enum
import json
from collections.abc import Iterable
from dataclasses import dataclass, replace
from urllib.parse import parse_qsl

from burpweb.burp_xml import Record


class Tier(enum.Enum):
    EXACT = "EXACT"
    FALLBACK = "FALLBACK"
    HEAD = "HEAD"
    MISS = "MISS"


@dataclass(frozen=True)
class Incoming:
    scheme: str
    host: str
    port: int
    method: str
    path: str
    query: str
    body: bytes
    content_type: str = ""


def normalize_query(query: str) -> tuple:
    return tuple(sorted(parse_qsl(query, keep_blank_values=True)))


def normalize_body(body: bytes, content_type: str) -> tuple:
    if not body:
        return ("raw", b"")
    mime = content_type.split(";", 1)[0].strip().lower()
    if mime == "application/x-www-form-urlencoded":
        return ("form", tuple(sorted(parse_qsl(body.decode("latin-1"), keep_blank_values=True))))
    if mime == "application/json" or mime.endswith("+json"):
        try:
            return ("json", json.dumps(json.loads(body), sort_keys=True, separators=(",", ":")))
        except ValueError:
            pass
    return ("raw", body)


class Matcher:
    def __init__(self, records: Iterable[Record]):
        self._exact: dict[tuple, Record] = {}
        self._success: dict[tuple, Record] = {}
        self._any: dict[tuple, Record] = {}
        for rec in records:
            base = (rec.scheme, rec.host.lower(), rec.port, rec.method.upper(), rec.path)
            exact = base + (
                normalize_query(rec.query),
                normalize_body(rec.request_body, rec.request_content_type),
            )
            _keep_latest(self._exact, exact, rec)
            _keep_latest(self._any, base, rec)
            if rec.status < 400:
                _keep_latest(self._success, base, rec)

    def match(self, req: Incoming) -> tuple[Record | None, Tier]:
        found = self._lookup(req)
        if found:
            return found
        if req.method.upper() == "HEAD":
            found = self._lookup(replace(req, method="GET"))
            if found:
                return found[0], Tier.HEAD
        return None, Tier.MISS

    def _lookup(self, req: Incoming) -> tuple[Record, Tier] | None:
        base = (req.scheme.lower(), req.host.lower(), req.port, req.method.upper(), req.path)
        exact = base + (normalize_query(req.query), normalize_body(req.body, req.content_type))
        if exact in self._exact:
            return self._exact[exact], Tier.EXACT
        rec = self._success.get(base) or self._any.get(base)
        if rec is not None:
            return rec, Tier.FALLBACK
        return None


def _keep_latest(index: dict[tuple, Record], key: tuple, rec: Record) -> None:
    if key not in index or index[key].index < rec.index:
        index[key] = rec
```

```python
"""Make a captured response safe to send again to a browser."""

from __future__ import annotations

import gzip
import zlib
from collections.abc import Iterable

# Connection-level headers: meaningless when replaying, and illegal over HTTP/2.
HOP_BY_HOP = {"connection", "keep-alive", "proxy-connection", "transfer-encoding", "upgrade", "te", "trailer"}
_DROP = HOP_BY_HOP | {"content-length", "alt-svc"}


def dechunk(body: bytes) -> bytes:
    """Decode a chunked transfer-encoded body; raise ValueError if it isn't validly chunked."""
    out = bytearray()
    pos = 0
    while True:
        eol = body.find(b"\r\n", pos)
        if eol < 0:
            raise ValueError("missing chunk size line")
        size_text = body[pos:eol].split(b";", 1)[0].strip()
        try:
            size = int(size_text, 16)
        except ValueError:
            raise ValueError(f"bad chunk size {size_text[:20]!r}") from None
        if size < 0:
            raise ValueError("negative chunk size")
        pos = eol + 2
        if size == 0:
            return bytes(out)
        if body[pos + size : pos + size + 2] != b"\r\n":
            raise ValueError("truncated chunk")
        out += body[pos : pos + size]
        pos += size + 2


def clean_response(headers: Iterable[tuple[str, str]], body: bytes) -> tuple[list[tuple[str, str]], bytes]:
    headers = list(headers)
    if any(k.lower() == "transfer-encoding" and "chunked" in v.lower() for k, v in headers):
        try:
            body = dechunk(body)
        except ValueError:
            pass
    out = [(k, v) for k, v in headers if k.lower() not in _DROP]
    encoding = ", ".join(v for k, v in out if k.lower() == "content-encoding").strip().lower()
    if encoding and _decodes(encoding, body) is False:
        out = [(k, v) for k, v in out if k.lower() != "content-encoding"]
    out.append(("Content-Length", str(len(body))))
    return out, body


def _decodes(encoding: str, body: bytes) -> bool | None:
    """Whether body is valid for encoding; None when we can't check that encoding."""
    try:
        if encoding in ("gzip", "x-gzip"):
            gzip.decompress(body)
        elif encoding == "deflate":
            try:
                zlib.decompress(body)
            except zlib.error:
                zlib.decompress(body, -zlib.MAX_WBITS)
        elif encoding == "br":
            try:
                import brotli
            except ImportError:
                return None
            brotli.decompress(body)
        else:
            return None
    except Exception:  # each decoder raises its own error types
        return False
    return True
```

"""mitmproxy addon that answers every request from the Burp capture."""

from __future__ import annotations

import collections
import html
import sys
import time
from http.client import responses as REASONS
from typing import TextIO

from mitmproxy import http

from burpweb.cleanup import clean_response
from burpweb.matcher import Incoming, Matcher, Tier

MISS_PAGE = """<!doctype html>
<meta charset="utf-8">
<title>Not in snapshot</title>
<body style="font-family: sans-serif; margin: 2em">
<h1>Not in snapshot</h1>
<p>burpweb has no captured response for:</p>
<pre>{method} {url}</pre>
</body>
"""


class Replay:
    def __init__(self, matcher: Matcher, out: TextIO | None = None):
        self.matcher = matcher
        self.out = out or sys.stdout
        self.misses: collections.Counter[str] = collections.Counter()

    def request(self, flow: http.HTTPFlow) -> None:
        req = flow.request
        path, _, query = req.path.partition("?")
        record, tier = self.matcher.match(
            Incoming(
                scheme=req.scheme,
                host=req.host,
                port=req.port,
                method=req.method,
                path=path or "/",
                query=query,
                body=req.raw_content or b"",
                content_type=req.headers.get("content-type", ""),
            )
        )
        url = req.pretty_url
        if record is None:
            self.misses[f"{req.method} {url}"] += 1
            page = MISS_PAGE.format(method=html.escape(req.method), url=html.escape(url))
            flow.response = http.Response.make(404, page, {"Content-Type": "text/html; charset=utf-8"})
            self._log(tier, req.method, url, 404)
            return

        headers, body = clean_response(record.response_headers, record.response_body)
        if req.method.upper() == "HEAD":
            body = b""
        now = time.time()
        flow.response = http.Response(
            http_version=b"HTTP/1.1",
            status_code=record.status,
            reason=REASONS.get(record.status, "").encode(),
            headers=http.Headers([(k.encode("latin-1"), v.encode("latin-1")) for k, v in headers]),
            content=body,  # raw bytes: keeps any Content-Encoding intact
            trailers=None,
            timestamp_start=now,
            timestamp_end=now,
        )
        index = record.index if tier in (Tier.FALLBACK, Tier.HEAD) else None
        self._log(tier, req.method, url, record.status, index)

    def done(self) -> None:
        print(self.summary(), file=self.out, flush=True)

    def summary(self) -> str:
        if not self.misses:
            return "No misses: every request was answered from the snapshot."
        lines = [f"--- {len(self.misses)} unique URL(s) not in snapshot ---"]
        lines += [f"{count:>5}  {key}" for key, count in self.misses.most_common()]
        return "\n".join(lines)

    def _log(self, tier: Tier, method: str, url: str, status: int, burp_index: int | None = None) -> None:
        extra = f"  [burp #{burp_index}]" if burp_index is not None else ""
        print(f"{tier.value:<8} {method} {url}  -> {status}{extra}", file=self.out, flush=True)
```

        "browser.cache.disk.enable": False,
    }

def prepare_profile(profile: Path, port: int, ca_pem: Path, certutil: str) -> None:
    profile.mkdir(parents=True, exist_ok=True)
    (profile / "user.js").write_text(user_js(port))
    db = f"sql:{profile}"
    if not (profile / "cert9.db").exists():
        subprocess.run([certutil, "-N", "-d", db, "--empty-password"], check=True, capture_output=True)
    # Re-add every time so a regenerated CA (or another --confdir) replaces the old one.
    subprocess.run([certutil, "-D", "-d", db, "-n", CERT_NICKNAME], capture_output=True)
    subprocess.run(
        [certutil, "-A", "-d", db, "-n", CERT_NICKNAME, "-t", "C,,", "-i", str(ca_pem)],
        check=True,
        capture_output=True,
    )


def manual_instructions(port: int, ca_pem: Path) -> str:
    return (
        "Set up a browser by hand:\n"
        f"  1. Set its HTTP and HTTPS proxy to 127.0.0.1:{port}\n"
        f"  2. Import {ca_pem} as a trusted certificate authority (for websites)"
    )


class FirefoxLauncher:
    """mitmproxy addon: once the proxy is running (so its CA exists), open Firefox."""

    def __init__(self, *, port: int, confdir: Path, start_url: str, profile: Path = DEFAULT_PROFILE, out: TextIO | None = None):
        self.port = port
        self.ca_pem = Path(confdir) / "mitmproxy-ca-cert.pem"
        self.start_url = start_url
        self.profile = profile
        self.out = out or sys.stdout
        self.process: subprocess.Popen | None = None

    def running(self) -> None:
        firefox = shutil.which("firefox")
        certutil = shutil.which("certutil")
        missing = [name for name, found in (("firefox", firefox), ("certutil", certutil)) if not found]
        if missing:
            self._say(f"--browser: {', '.join(missing)} not found on PATH.\n" + manual_instructions(self.port, self.ca_pem))
            return
        try:
            prepare_profile(self.profile, self.port, self.ca_pem, certutil)
        except (OSError, subprocess.CalledProcessError) as e:
            self._say(f"--browser: could not set up the Firefox profile ({e}).\n" + manual_instructions(self.port, self.ca_pem))
            return
        self.process = subprocess.Popen(
            [firefox, "-profile", str(self.profile), "-no-remote", "-new-instance", self.start_url],
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
        )
        self._say(f"Opened Firefox (profile {self.profile}) at {self.start_url}")

    def _say(self, text: str) -> None:
        print(text, file=self.out, flush=True)

"""burpweb command line: browse a Burp Suite HTTP history export offline."""

from __future__ import annotations

import argparse
import asyncio
import collections
import signal
import sys
from pathlib import Path

from burpweb.addon import Replay
from burpweb.burp_xml import BurpXmlError, LoadResult, load
from burpweb.matcher import Matcher


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="burpweb", description="Browse a Burp Suite HTTP history export offline.")
    sub = parser.add_subparsers(dest="command", required=True)

    serve = sub.add_parser("serve", help="run the replay proxy")
    serve.add_argument("export", type=Path, help="Burp XML from Proxy > HTTP history > Save items")
    serve.add_argument("--port", type=int, default=8081, help="proxy port (default: %(default)s)")
    serve.add_argument("--browser", action="store_true", help="open a Firefox profile preconfigured for the proxy")
    serve.add_argument(
        "--confdir",
        type=Path,
        default=Path("~/.mitmproxy"),
        help="mitmproxy config and CA directory (default: %(default)s)",
    )

    show = sub.add_parser("list", help="show the captured origins")
    show.add_argument("export", type=Path, help="Burp XML from Proxy > HTTP history > Save items")
    return parser


def main(argv: list[str] | None = None) -> int:
    args = build_parser().parse_args(argv)
    try:
        result = load(args.export)
    except BurpXmlError as e:
        print(f"error: {e}", file=sys.stderr)
        return 2
    if not result.records:
        print(
            f"error: no usable items in {args.export}. Export with Proxy > HTTP history > "
            "select items > Save items, and make sure the items have responses.",
            file=sys.stderr,
        )
        return 1
    print(load_summary(result), flush=True)
    if args.command == "list":
        print(format_hosts(result))
        return 0
    return serve(result, port=args.port, confdir=args.confdir.expanduser().resolve(), browser=args.browser)


def load_summary(result: LoadResult) -> str:
    origins = {r.origin for r in result.records}
    lines = [
        f"Loaded {len(result.records)} items across {len(origins)} origin(s); "
        f"skipped {result.skipped_no_response} without a response, {len(result.malformed)} malformed."
    ]
    lines += [f"  malformed item #{index}: {reason}" for index, reason in result.malformed]
    return "\n".join(lines)


def format_hosts(result: LoadResult) -> str:
    counts: collections.Counter[str] = collections.Counter()
    paths: dict[str, set[str]] = collections.defaultdict(set)
    for rec in result.records:
        counts[rec.origin] += 1
        paths[rec.origin].add(rec.path)
    lines = [f"{'ITEMS':>6} {'PATHS':>6}  ORIGIN"]
    lines += [f"{n:>6} {len(paths[origin]):>6}  {origin}" for origin, n in counts.most_common()]
    return "\n".join(lines)


def serve(result: LoadResult, *, port: int, confdir: Path, browser: bool) -> int:
    addons: list = [Replay(Matcher(result.records))]
    if browser:
        from burpweb.browser import FirefoxLauncher

        addons.append(FirefoxLauncher(port=port, confdir=confdir, start_url=result.records[0].url))
    print(
        f"Replay proxy on http://127.0.0.1:{port}  (CA: {confdir / 'mitmproxy-ca-cert.pem'})  Ctrl-C to stop.",
        flush=True,
    )
    try:
        asyncio.run(run_proxy(addons, port=port, confdir=confdir))
    except SystemExit as e:  # mitmproxy exits like this when startup fails, e.g. port in use
        if e.code:
            print(f"error: the proxy failed to start (see above). If port {port} is busy, pick another with --port.", file=sys.stderr)
            return 1
    return 0


async def run_proxy(addons: list, *, port: int, confdir: Path) -> None:
    from mitmproxy.options import Options
    from mitmproxy.tools.dump import DumpMaster

    master = DumpMaster(
        Options(listen_host="127.0.0.1", listen_port=port, confdir=str(confdir)),
        with_termlog=True,
        with_dumper=False,
    )
    # lazy + no upstream cert: mitmproxy never opens a connection to the real server.
    master.options.update(connection_strategy="lazy", upstream_cert=False, http3=False, termlog_verbosity="warn")
    master.addons.add(*addons)
    loop = asyncio.get_running_loop()
    for sig in (signal.SIGINT, signal.SIGTERM):
        loop.add_signal_handler(sig, master.shutdown)
    await master.run()
```

`README.md`:
````markdown
# burpweb

Browse a website you tested in Burp Suite **offline**, at its real URLs, from your Burp HTTP history.
burpweb runs a local replay proxy (built on mitmproxy) that answers every request from the capture.
It never contacts the real target.

## Install

```bash
uv sync            # inside this repo
uv run burpweb --help
```

## 1. Export from Burp

Proxy → HTTP history → select all (Ctrl-A) → right-click → **Save items**.
Keep **"Base64-encode requests and responses"** ticked.
Using a `.burp` project? Open it in Burp first, then export the same way.

## 2. Serve it

```bash
uv run burpweb list history.xml               # what's in the capture
uv run burpweb serve history.xml --browser    # proxy on 127.0.0.1:8081 + preconfigured Firefox
```

`--browser` uses its own Firefox profile (`~/.local/share/burpweb/firefox-profile`) and trusts the mitmproxy CA
only there. Your normal browser and system trust store are not touched.
Without `--browser`, point any browser's HTTP and HTTPS proxy at `127.0.0.1:8081` and trust
`~/.mitmproxy/mitmproxy-ca-cert.pem`.

## How requests are matched

1. **EXACT**: same scheme, host, port, method, path, query (any order) and body (form and JSON compared normalized). The most recent capture wins.
2. **FALLBACK**: same path, ignoring query and body. This uses the most recent capture with status < 400, else the most recent with any status.
3. **HEAD**: answered from the GET capture, with no body.
4. **MISS**: a 404 page saying "Not in snapshot". Misses are summarized when you press Ctrl-C.

Each request is logged as `EXACT`, `FALLBACK`, `HEAD` or `MISS`.
Not supported: WebSockets (not in Burp's XML export) and native `.burp` files.
````
